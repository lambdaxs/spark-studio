# 文档索引（给下一任 AI）

Spark Studio 是单用户知识工作台。先读文档，再改代码。不要把已经否掉的能力（GitHub、分组 UI、真发布、全局聊天）当默认方案。

| 文档 | 用途 |
| --- | --- |
| [product.md](./product.md) | **当前产品**：背景、愿景、模块、数据、主路径 |
| [design-history.md](./design-history.md) | **怎么讨论出来的**：锁定决策、后来修正、给下一任的工作方式 |
| [product-design-spec.md](./product-design-spec.md) | **画界面**：视觉约束和分屏提示词，不是功能全集 |

工作习惯：先复述需求并列出会改模型的分歧，等人确认再开工；一次只钉一刀。
